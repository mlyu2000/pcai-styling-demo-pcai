PCAI Styling Demo — Data Flow

what data moves, in what form, and where it lands · base64 in → data-URIs back (flow) · PNG/JPEG bytes → MP4 on NFS (video) · the stateful stores

In-memory vs durable

  • • Flow images: base64 ↔ PIL, per request, never written to disk
  • • Durable writes: MP4, templates JSON, baseline.json → results PVC
  • • Weights on the shared pcai-wan-store PVC (not per-request data)

Transform points

  • • _dims_from_image — the single normalization every image passes through (768/16)
  • • _flow_enc — one shared output size per call, back to PNG data-URI
  • • _faststart_mp4 — pure-stdlib moov re-atomize (browsers need it)

Security of data

  • • External keys: request body → ContextVar → Bearer header only
  • • On-prem keys: K8s Secret → env var → header (no files, no logs of values)
  • • Design IP stays in-cluster on the on-prem path — no egress
