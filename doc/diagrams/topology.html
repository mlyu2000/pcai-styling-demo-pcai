PCAI Styling Demo — CS1 Deployment Topology

HPE Ezmeral Kubernetes 1.32 (airgapped) · 3 GPU nodes, 4× A100-40GB · deployed via Helm (helm-chart/) + MLIS API · airgapped registry registry.ctc.sg.lab:5000

Deploy (helm-chart/)

  • • Single source of truth: values.yaml (domain, ns, endpoints, model identity, secrets-by-name)
  • • helm upgrade --install replaces kubectl apply (manifests/ = frozen reference)
  • • Airgapped: images built on bastion → registry.ctc.sg.lab:5000
  • • KUBECONFIG must be native Windows path (MSYS /c/ fails for kubectl.exe)

Inference (MLIS)

  • • POST /api/v1/models + /deployments (PackagedModel, pvc:// weight mounts)
  • • Node move = Postgres UPDATE node_selectors + status=Deploying → ListenLoop new revision
  • • Equal-priority (mlis-gpu 8000) preemption REFUSED — move models deliberately
  • • Weights on shared NFS: re-pin without re-seed (~15–20min load)

State & durability

  • • Results PVC (NFS): MP4 + artifacts + templates — survives restarts
  • • pcai-wan-store (NFS): model weights — shared across nodes
  • • Secrets: litellm-key / mlis-key / styling-api-key (never committed)
  • • OpenClaw skills on agent-state PVC (durable); gateway re-scans at boot only
